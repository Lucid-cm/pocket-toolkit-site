# Pocket Toolkit

[![maintenance: active](https://statusbadge.onrender.com/badge/N6au1hrImRgiADhyNsvUkg.svg)](https://lucid-cm.github.io/pocket-toolkit-site)

Four lightweight Python tools for developers, builders and terminal enthusiasts.

## What's inside

- Pocket Agent — AI-assisted terminal tasks.
- Save Guardian — Automatic local game-save backups.
- Approval Auditor — Read-only wallet approval auditing.
- Surface Scan — Passive security checks for systems you own.

## Product

A collection of practical utilities designed to run on your own device.
